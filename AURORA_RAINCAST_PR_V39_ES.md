# PR-WX v3.9.0 — AURORA RainCast PR Impact Ready

## Propósito

Esta versión continúa las mejoras del mapa de lluvia en vivo. El objetivo es que el usuario pueda identificar con mayor rapidez dónde está lloviendo, dónde podría llover en la próxima hora y qué áreas requieren mayor vigilancia preventiva.

## Mejoras principales

- Panel de diagnóstico experimental de sistemas tropicales.
- Tablero de impacto potencial para lluvia, inundación rápida y alertas severas.
- Verificación de salud de servicios para alertas, punto base y pronóstico por hora.
- Mayor claridad visual para nubes de lluvia y trayectorias.
- Soporte reforzado para vista desktop y mobile en la versión empacada.

## Página principal

- `/desktop/live-rain.html`

## Validación

- Validar siempre con NOAA, NWS San Juan, NHC y manejo de emergencias.
- El modelo no emite avisos oficiales.
- La trayectoria tropical y la clasificación de sistemas son experimentales.
