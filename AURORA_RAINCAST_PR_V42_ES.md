# PR-WX v4.2.0 — AURORA RainCast PR Operations Cockpit

Esta versión añade un centro operacional sobre la página `desktop/live-rain.html` para apoyar decisiones rápidas durante eventos de lluvia en Puerto Rico.

## Componentes añadidos

- `desktop/live-rain-v42.css`
- `desktop/live-rain-v42.js`
- Integración visual en `desktop/live-rain.html`
- Actualización del cache en `desktop/service-worker.js`
- Versión interna `4.2.0`

## Funciones principales

- Centro operacional AURORA v4.2.
- Estado decisional: vigilancia normal, preventiva o alta.
- Municipio crítico por pico de precipitación 0–3 horas.
- Matriz operacional por municipio.
- Reporte operacional listo para copiar.
- Exportación JSON del estado de lluvia y alertas.
- Botón de impresión.
- Checklist decisional.

## Uso recomendado

Esta versión debe usarse como apoyo visual y operacional para monitoreo rápido. No sustituye los productos oficiales de NOAA, NWS San Juan, NHC ni las instrucciones de manejo de emergencias.
