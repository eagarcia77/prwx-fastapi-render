# PR-WX v4.3.0 — AURORA RainCast PR Briefing Center

## Propósito

Esta versión añade un centro de briefing operacional al mapa de lluvia en vivo. El objetivo es convertir la lectura del radar y el nowcast municipal en un resumen práctico que pueda copiarse, imprimirse o exportarse para una reunión rápida, una coordinación interna o una evaluación preventiva.

## Mejoras principales

- Centro de briefing AURORA v4.3.
- Matriz municipal 0–3 horas.
- Identificación del municipio crítico.
- Estado decisional: normal, monitoreo, preventiva o alta.
- Reporte operacional listo para copiar.
- Exportación JSON del briefing.
- Modo kiosco para presentación en pantalla grande.
- Botón de impresión.

## Página principal

- `/desktop/live-rain.html`

## Validación

La herramienta es experimental. Para decisiones críticas se debe validar con NWS San Juan, NOAA, NHC y manejo de emergencias.
