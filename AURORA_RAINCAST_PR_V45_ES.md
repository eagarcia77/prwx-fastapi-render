# PR-WX v4.5.0 — AURORA RainCast PR Cloud Boost

## Propósito

Esta versión refuerza la visibilidad de nubes sobre Puerto Rico. El problema principal atendido es que las nubes GOES podían aparecer muy débiles o no distinguirse bien sobre el mapa base.

## Mejoras principales

- Mapa reforzado de nubes sobre Puerto Rico.
- Capa GOES infrarroja activa por defecto y con mayor contraste visual.
- Capa GOES visible como apoyo cuando hay luz diurna.
- Radar de lluvia encima de las nubes.
- Controles de opacidad separados para IR, visible y radar.
- Botones rápidos: Todo, Solo IR, Visible + IR y Radar + IR.
- Enfoque rápido por municipio para Juana Díaz, Ponce, San Juan, San Germán, Vieques y Culebra.
- Actualización automática cada dos minutos para reducir problemas de caché.

## Validación

- La capa IR debe usarse cuando las nubes visibles se vean débiles o durante la noche.
- El sistema continúa siendo experimental.
- Para decisiones críticas se debe validar con NOAA, NWS San Juan, NHC y manejo de emergencias.
